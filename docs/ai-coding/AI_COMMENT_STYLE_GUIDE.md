# AI 记忆服务注释规范

## 原则

- 优先让代码自解释，注释只解释代码看不出的边界、风险和副作用。
- 注释重点说明记忆授权、租户隔离、患者隔离、脱敏、删除同步、Qdrant 派生索引、Redis 缓存失效和失败降级。
- 不做逐行翻译，不用注释保留废弃代码、临时 SQL、调试 main 或整块旧实现。

## 必须注释的场景

- 记忆写入策略为什么接受、拒绝或进入待确认。
- 召回为什么限制条数、token、用途或字段。
- 删除、归档、脱敏为什么要同步 MySQL、Qdrant、Redis 和任务队列。
- Qdrant 命中后为什么还要回查 MySQL。
- Redis key 为什么包含租户、患者、会话或用途。
- 跨服务 RPC 为什么需要调用方、患者、来源租户和 purpose。

## 禁止

- 禁止在注释里写真实密钥、数据库地址、个人电脑绝对路径。
- 禁止把敏感明文样例写进测试注释或文档。
- 禁止用“临时”“以后再说”这类无法维护的注释替代设计边界。
